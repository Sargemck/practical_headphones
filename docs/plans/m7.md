# M7 plan: release prep

Branch `m7-release`, based on `m6-autoconnect` (#9). Implemented straight after the plan, per Baris's 2026-11-03 instruction.

## In this PR

1. **Launcher icon.** An adaptive icon (`mipmap/ic_launcher`): the Material headphones glyph on a dark blue background, with a monochrome layer for themed icons. No Bose marks. minSdk 31, so no raster fallbacks.
2. **Release signing.** Read from `keystore.properties` at the repo root (gitignored) when it exists. Otherwise the release is unsigned, which is what F-Droid builds and signs itself.
3. **Reproducible build.** `dependenciesInfo` is off (no signing block in the APK).
   - Check: `./gradlew clean assembleRelease` twice must give byte-identical unsigned APKs.
   - Cross-machine reproducibility is F-Droid's check and can't be done here.
4. **Privacy.**
   - `PRIVACY.md`: what's stored on the phone, nothing collected, and why each permission exists.
   - `android:allowBackup="false"`: the shared preferences hold the headphones' address and would otherwise go to cloud backup, which would make "nothing leaves your phone" untrue.
5. **F-Droid metadata.** `fastlane/metadata/android/en-US`: title, short and full description, changelog for versionCode 1, and 4 phone screenshots from the light goldens.
6. **README.** What it does, requirements, privacy, building, credits, "not affiliated with Bose".

## Not in this PR (Baris's decisions)

- **The release keystore.** Baris creates it and backs it up outside the repo. The README says how to point the build at it.
- **Play.** Organisation or personal account. A personal account needs 12 testers opted in for 14 days of closed testing.
- **versionName.** It's still 0.0.1. Set it when the release date is known.
